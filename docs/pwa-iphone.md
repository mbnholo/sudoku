# Install Sudoku on iPhone

1. Connect to the internet and open the [published Sudoku site](https://mbnholo.github.io/sudoku/) in **Safari**. Wait for the game to load and for the status to show **Ready for airplane mode**.
2. Tap **Share** (the square with an up arrow), then **Add to Home Screen**. Depending on the iOS version, this option may be under **Edit Actions** or the share menu's **More** section.
3. Keep the name **Sudoku**. If Safari offers **Open as Web App**, enable it, then tap **Add**.
4. Open Sudoku from its new Home Screen icon once while online. To check offline play, turn on airplane mode and reopen the icon.

The installed app uses the same site and can update when you reconnect and reopen it. Games and statistics are stored on this iPhone only. Clearing Safari website data or removing the web app may erase them; there is no account or cross-device sync.
